# Basic yt-dlp

A simple YouTube downloader built with Python using the [yt-dlp](https://github.com/yt-dlp/yt-dlp) library.

## Requirements

* Python 3.x
* `yt-dlp`

## Installation

First, make sure Python is installed on your computer.

Then install the `yt-dlp` library using:

```bash
pip install yt-dlp
```

## Usage

Run the Python program and follow the instructions provided by the application.
